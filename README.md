# Game Portal Web App

A clean, responsive, and scalable mini-game portal built with HTML5, CSS3, and Vanilla JavaScript. It allows users to browse, search, filter, and launch HTML5 games directly inside an embedded modal window.

---

## Features

* Instant Search: Real-time filtering by game title or category.
* Dynamic Categories: Automatically generates filter buttons based on available game categories.
* Embedded Game Runner: Play games directly inside a popup modal powered by an iframe with full-screen support.
* Future-Proof and Scalable: Easily add new games by dropping a folder into the root directory and registering it in a single JavaScript configuration file.
* Dark Arcade UI: Modern glassmorphism design with responsive support for desktop, tablet, and mobile.
